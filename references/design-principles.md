# 设计原则

| 原则 | 设计决定 |
|---|---|
| 长期健康与完整身体机能 | 训练服务全面身体能力和可持续提高，兼顾各维度功能与恢复成本 |
| 生活与运动用途明确 | 将生活挑战和其他运动的准备需求转成所需能力，项目名称和单项成绩不代替最终用途 |
| 功能性建设与补强 | 根据共同身体需求和薄弱环节选择刺激，兼顾已有能力的提高与实际任务整合 |
| 体重与体成分作为结果 | 训练提供支持，以能力、身体功能和健康变化为主要评价，体重趋势作补充；相关目标按用户需求处理 |
| 目标决定处方 | 为重点能力选择对应刺激、剂量和递进；完成课表不能替代能力提高目标 |
| 少量问清、明确给意见 | 起点、目标与时间条件足够后由Skill提出安排及取舍；只追问会改变处方的缺口 |
| 当前能力决定起点 | 使用近期熟悉动作、稳定训练暴露和自述能力，不以历史最佳或目标表现倒推初始强度 |
| 默认正常执行、预先递进 | 写出每周具体变化与幅度，正常执行后按计划继续；反馈用于纠偏，不设日志或测试进阶门槛 |
| 全面方向、发展与维持并存 | 多项同步提高或阶段重点突破均可（单阶段主导项目只有一个，属编排取舍，见 concurrent-training 第五节，不是身体能力上限）；发展能力获得提高刺激，维持能力保留针对性刺激；减量时不把所有刺激一同降成热身 |
| 周内与周间均波动 | 周内分配强度、容量、速度与恢复成本；周间改变剂量或侧重，不为凑波动增加陌生高强度 |
| 最多12周只训练 | 完整12周采用四个3周阶段；各阶段承担发展任务，无测试课或测试前减量 |
| RPE＋参考重量共同指导力量负荷 | 先定次数与目标RPE，再给参考重量（取 TR＝训练中实际完成过的重量，标组次与日期与每手／总重）；TR 是起点不是完成要求，目标RPE不机械逐周加码；取不到就标待补并首组自校准，不许静默留空 |
| 多项目共同编排 | 汇总力量、跑步、游泳及弹跳的局部与全身负荷；明确优先保护哪项训练的质量 |
| 动作按目的选 | 选择能独立完成、有设备、能稳定加载的动作；复杂、单腿或不稳定不自动更好。**骨架与动作分层取源**：段序、槽位、配对与组结构照原典（Boyle 那套完全健康者的框架，不因限制降级），槽内动作从知识库全库选最优——判据先对11项能力与成绩表，再用医学安全那一路过滤；不引入知识库之外的外部课程动作 |
| 有效且可恢复 | 根据起点选择剂量与休息，在计划中预留恢复空间；不把10%周增量、三加一或统一间隔当万能规则。**但「不统一」不等于「不给数」**：主项组间按强度档给 2–3 分钟，辅助三联 ≤1 分钟，速度 90 秒，增强式／药球 60 秒——每格都要有数，差异是分档产生的，不是留空的理由 |
| 修改最小必要范围 | 单次问题先改单次及直接关联；持续条件或多能力受影响再改周、阶段与整体 |

波动不只是换动作。力量课可分容量、较重负荷与快速输出；耐力课可分轻松持续、技术与较强刺激。每阶段只安排支持当前目标且已有能力承接的刺激，不要求每周把所有方法集齐。

若条件不足以同时提高全部目标，Skill应指出具体冲突，明确建议重点发展、维持或延后哪项能力，并说明代价。在直接排课授权范围内按推荐方案展开；用户提出不同优先级再调整，不要求用户替Skill选择组次、配速、恢复或训练排序。

降载有明确用途：可因新异常、持续完成困难、条件改变或阶段任务安排而调整。不得因为到了第4、8、12周就自动减量；也不能仅凭存在轻日便认定恢复充分。

## 见证机制：进步要看得见，但不加测试

对不备赛的人，「练完没有可见变化」是比强度更常见的放弃原因。**每 3–4 周用同一个自选标尺记一次**，标尺由用户自己选：同路线 E 跑同 RPE 的距离、同动作同 RPE 的次数、球后半场还跑不跑得动。

**只记录，不排课、不减量、不进能力覆盖**：不设测试周、不测 CSS、不比成绩表。记录只出现在周历「见证」备注里。三个月内同一把尺子在变好，就是进步；**标尺没动时按训练侧复核**：起点是否估错、计划实际执行了多少、刺激与递进是否足够、技术是否还不熟、项目叠加是否过量、身体反应如何、条件是否变了——不先查强度，**也不要营养或睡眠资料**，本 skill 不提供这两类管理方案。
