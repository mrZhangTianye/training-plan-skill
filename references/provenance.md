# 取材与出处口径

写计划、答疑、被评审时，用这份口径判断一条结论能不能挂到书上。主文件里只留偏离表结论，怎么核在这里。

本体系借 Boyle 四阶段骨架与三天／四天／两天模板；偏离结论表见 [SKILL.md](../SKILL.md#与原书的明确偏离)。写计划、被追问、做评审时照这张表答，不要把这些说成「书里写的」。

**核「原书写的」要回原剂量表逐格核，不看汇总表。** 归到书上的阶段次数、组数区间必须对原书那张表核（须使用有权访问的原书；公开包不提供原书转写）；拿不到原表就标「未核」，不写成「书里写的」。**重写剂量表前先 `grep -rn "5/3/1" SKILL.md references/` 扫一遍全包**——重写一张表不继承别处的禁令，删过的错内容最容易在这一步原样写回，还顺手给它自造定义。**依据与来历分开**：讲「为什么这个数就是它」的原书对照要留（如 Page 323 的 Bench 5RM ＝ hang clean 5RM ＝ 后脚抬高分腿蹲 5RM ＝ 引体 5RM），讲「这个错是怎么被发现」的删掉；评审说「这处重复、压成一句」时先判它是副本还是依据——副本合并，依据保留。

**三类来源分开标，混写就会被当成书里的**：① 书里的——要能回到具体表／页，拿不到原文就写「未核」；② 本包的取舍——写「本包自定」，如阶段长度、3/10 只作当日上限、周高强度课上限；③ 用户个人条件——可用时长、器械、伤病，只进 `plan.json`，不进规则。一条结论只属于其中一类；评审或答疑时先问「这条是哪一套发的」，再判它对不对。**讨论中临时新增的结构（另切块、排日历降量周、由目标项定义阶段、把某阶段当减负谷）默认算「无出处的第四类」，回原文核不到就不进包**。

**引外部教材的页码要区分 PDF 页与印刷页**：核验时使用的 Therapeutic Exercise 文本提取件用 `## Page N` 标的是 **PDF 页**，印刷页 = PDF 页 − 35（全书页眉 500 处偏移一致）；抗阻训练注意事项＝书页 202、关节次日反应＝书页 136、拉伸后 24 小时反应＝书页 1081。写成「书页 N（PDF N+35）」，只写 PDF 页对方按页码翻不到。扫描版无文字层时先 OCR 取原文再引，无原文不给页码。

**跨语言／跨版本不换算页码**：同一本书的中文版与英文版页码是两套独立编号，没有线性偏移可用——英文版 `## Page N`（PDF 抽取页标）里某动作落在 377–388，中文版印刷页却可能在 193。手里只有英文版时，**不能拿它的页标反推中文版页码**，一律标「中文版页码待核」并写清依据的文件名与版本；中文版到手后按单页重核。**页码列不混写单页与章节区间**（`404–416` 这种写「第 X 章」另标一列），否则「页」这一列既不能翻也不能对。

**译名与页码一样要能回溯到哪份文件**：写进对照表的中文译名，要么有可访问的中文版原文、要么标「据包内已统一名」，两者选一写进表下，不留「核过但没说核的哪本」。英文文字层搜不到不等于书里没有——名字可能是中文版表格里才出现的（OCR 才拿得到），但不能因此把凭印象拟的名当译名用。
