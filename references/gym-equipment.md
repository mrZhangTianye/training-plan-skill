# 器械配置：力量房有什么，就填什么主项位

只算训练设备。泡沫轴、弹力带、迷你带这类辅具不计入配置。

动作名以[动作中英对照](exercise-names.md)为准。

## 一、设备清单

“书”列：✓ = 书中用到且有页码，— = 书中未提。

## 二、膝主导的功能性排序（书页 34）

从最弱到最强：

| 序 | 动作 | 靠什么维持稳定 |
|---|---|---|
| 1 | 仰卧蹬腿 | 器材全部稳定 |
| 2 | 站姿器械深蹲 | 器材提供稳定，双腿站立 |
| 3 | 杠铃深蹲 | 自己维持稳定，但仍双腿 |
| 4 | **单腿深蹲** | 自己维持，单腿支撑 |

书页 34：“单腿力量非常特殊，它不能通过双腿练习来培养。”页 95 又把“器械蹬腿、腿部伸展和屈腿练习”直称为“完全非功能性”。

**这条排序决定了降级路线：**器械不够时不是往下找替代，而是**直接跳到单腿**——第 1、2 两档本来就不该用。没深蹲架的时候，答案是后脚抬高分腿蹲与单腿深蹲，不是去排队等史密斯机。

## 三、逐项替代

**默认已有**：哑铃、杠铃、卧推凳、高位下拉、坐姿划船、单杠。以下逐项说没有时怎么办。

### 完全可提（丢了不影响）

| 没有 | 用什么 | 丢什么 |
|---|---|---|
| 壶铃 | 哑铃：哑铃摆起／哑铃高脚杯深蹲／哑铃土耳其起立 | 摆起的弹道感，其他无 |
| 沙袋、负重背心 | 提箱子行走、单臂负重走 | 躯干均匀负荷 |
| TRX | 反向划船（书 176：无需定期练习时的最佳动作） | 可调不稳定度 |
| 跳箱 | 台阶、稳固矮墙、楼梯 | 高度可调（多级台阶可解） |
| 栏架 | 标志物、跳箱横放、水瓶 | 过栏意象 |
| 椭圆机 | 划船机、风阻单车、游泳 | 无 |
| 划船机 | 风阻单车、椭圆机、游泳 | 水平拉＋有氧的组合 |
| 波速球 | 单腿站立、闭眼单腿站 | 无（书 47 也只在一个动作里用） |
| 敏捷梯 | 地面胶带、水瓶、锥桶 | 无（书中未提） |

### 降级可提（丢一点）

| 没有 | 用什么 | 丢什么 |
|---|---|---|
| **六角杠** | **哑铃硬拉**（最接近：中立握＋双侧负重）→ 杠铃硬拉 | 杠铃级负荷下的中立握 |
| **深蹲架** | 六角杠／哑铃硬拉＋单腿；负重蹲用悬吊或下拉器械辅助（书 95） | 杠铃负荷下双腿蹲。按书 34 排序损失可控 |
| **绳索 / 龙门架** | 弹力带做下劈、上拉、面拉 | 持续张力、阻力可量化 |
| **吊环** | TRX → 反向划船 | 可调不稳定度 |
| **风阻单车** | 划船机（最接近，全身参与） | 阻力随速度自动调整、零冲击 |
| **瑞士球** | 滑板屈腿 → 单腿臀桥 → 北欧腿弯举 | 膝屈的离心负荷 |

### 真缺口（替不了，标出来）

| 没有 | 勉强能做什么 | 缺什么 |
|---|---|---|
| **药球** | 下肢爆发用跳箱＋蹲跳补 | **上肢弹道与旋转爆发**（沙袋能抛不能砸，重物砸地伤人）。书 44 称其“训练爆发力的最佳工具之一” |
| **雪橇车** | 陡坡走＋划船机近似 | 无离心蹬伸＋水平阻力。书 84：“只能做一个练习可能就是推雪橇车” |
| **滑板** | 侧向滑步、侧弓步 | 站姿侧向滑行。书 45：“只有滑板才能让运动员以这种站姿做能量代谢训练” |

三个缺口的严重度不同：**药球缺的是能力方向上的一个角**（上肢弹道与旋转爆发没别的东西补），雪橇与滑板缺的是手段，有氧与下肢代谢仍能用其他器材满足。

## 四、垂直拉是硬条件

单杠或下拉器械**二选一必须有**。两个都没有 → 垂直拉整条方向暂缓，不找替代。

其余设备缺了都是降级或缺口，只有这一条是“有没有决定这一项练不练”。

## 五、四档配置

| 档 | 有 | 典型场景 |
|---|---|---|
| **A 全器械** | 杠铃＋架＋哑铃＋绳索＋单杠＋凳＋药球＋雪橇 | 商业健身房 |
| **B 无杠铃** | 哑铃＋绳索＋单杠＋凳＋药球 | 酒店、小型健身房 |
| **C 只有哑铃** | 一对可调哑铃（有凳或无凳） | 家里 |
| **D 纯自重** | 单杠（有就最好）＋地面 | 出差、旅行 |

## 六、八个主项位怎么填

| 主项位 | A 全器械 | B 无杠铃 | C 只有哑铃 | D 纯自重 |
|---|---|---|---|---|
| **双侧髂主导** | 六角杠硬拉 | 哑铃硬拉（最重） | 哑铃硬拉 | 单腿臀桥 ＋ 瑞士球屈腿 |
| **单侧髂主导** | 单腿直腿硬拉 | 哑铃单腿硬拉 | 哑铃单腿硬拉 | 自重单腿直腿硬拉 |
| **单侧膝主导①** | 后脚抬高分腿蹲 | 后脚抬高分腿蹲 | 后脚抬高分腿蹲 | 单腿深蹲（扶持） |
| **单侧膝主导②** | 单腿深蹲 | 分腿蹲 | 分腿蹲 | 分腿蹲 |
| **仰卧推** | 卧推 | 哑铃卧推（无凳改地板卧推※） | 哑铃卧推（无凳改地板卧推※） | 脚抬高俯卧撑 |
| **上斜推** | 上斜哑铃卧推 | 上斜哑铃卧推（有凳） | 上斜俯卧撑 | 下斜俯卧撑 |
| **垂直拉** | 引体向上 | 引体向上 或 下拉器械 | **暂缓** | 引体向上（有单杠）／**暂缓** |
| **水平拉** | 杠铃俯身划船 | 哑铃划船／绳索划船 | 哑铃划船 | 反向划船（牌下／栏杆下） |
| **核心** | 下劈／上拉、农夫行走 | 同 | 哑铃下劈／提箱子行走 | 平板侧撑、悬垂举腿（有杠） |
| **爆发段** | 药球胸前传球／猛摔砸球 | 同（无药球则跳箱） | 哑铃摆起、跳箱 | 蹲跳、跳箱（台阶） |

※ 地板卧推是**包内补充**，书中无此动作。无凳时用它，引用时必须标明来源。

## 七、每档明确缺什么

| 配置 | 不发展的能力 | 原因 |
|---|---|---|
| **B 无杠铃** | 髂与膝主导的最大力量上限 | 哑铃重量到顶就封顶 |
| **C 只有哑铃** | 垂直拉 ＋ 最大力量上限 | 无单杠无下拉机 |
| **D 纯自重** | 外部负荷带来的最大力量 | 只能靠单侧化与慢速离心 |

## 八、没有重量可加时，递进靠什么

| 手段 | 做法 |
|---|---|
| 单侧化 | 双腿蹲 → 后脚抬高分腿蹲 → 单腿深蹲 |
| 慢速离心 | 下放 4 秒，起 1 秒 |
| 加 ROM | 前脚垫高做分腿蹲，加深蹲幅度 |
| 加组 | 3 组 → 4 组 |
| 缩休息 | 60 秒 → 45 秒 |
| 加次数 | 8 次 → 12 次，到 12 次再加组 |

纯自重的真实短板是**下肢负荷不足**，补法是单侧化加慢速离心，不是加次数。

## 九、禁则

- 不把“垂直拉器材不可用”处理成“用水平拉替代”，只能标暂缓。
- 不用**手枪式深蹲**当单腿进阶（书页 105、114 反对）；练的是单腿深蹲。
- 不用**腿屈伸机 / 腿弯举机**（书页 124）、**腿举机**与**史密斯机**（书页 34）。
- 不把辅具（泡沫轴、弹力带、迷你带）算进器械配置。
- 不把“哑铃卧推”说成“卧推”；不把地板卧推说成书里有的动作。
- 不把固定器械当自由重量的等价替代：它能补容量，不补稳定与协调。
- 器械不够时往单腿跳，不往器械链的下游退。
- 不把**药球、雪橇车、滑板**写成有等价替代：这三件只能标缺口。
