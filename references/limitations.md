# 身体有局限时怎么训练

管的是**训练怎么改**，不做诊断、不判断病因、不承诺康复。用户拿医嘱来就按允许范围适配；没有医嘱时只按“哪个动作做不了”重排，不猜是什么病。

## 一、按模式分，不按诊断分

**本包的作业边界**：不判断病因、不下病名、不替医生做诊断。能做的是把「哪个动作、哪个方向、多大负荷会引出症状」记下来，据此换动作、降负荷、改方向——这是编排层面的事，不需要先知道是什么病。真要定性，交给能检查的人。

所以下文按**七个动作族**写，不按伤名写。用户自己就能判断“这个动作我做不了”，不需要先知道病名。

## 二、两类限制

| | **长期**（结构性） | **阶段性**（可逆） |
|---|---|---|
| 例 | 术后活动度永久受限、慢性关节病变、陈旧损伤 | 急性期、康复早中期、肌腱炎发作期 |
| 做法 | **换族**，并列明缺的能力 | **降级不换族**，保留模式本身 |
| 递进 | 在替代族里正常往上加 | 只往回走，不往前推 |
| 写法 | 进基线，永久有效 | 写明期限与复评条件 |

最容易出的错：用阶段性限制去换动作族——急性期把深蹲永久删了，好了也没加回来。

## 三、愈合三期，各期能做什么

| 期 | 时间 | 允许什么 | 禁止什么 |
|---|---|---|---|
| **急性期** | 伤后数日 | 无痛范围活动；肿痛时按医嘱处理 | 不把冰敷当常规处理（证据不一，不必天天做）；用药按医嘱，本包不判断 |
| **亚急性期** | 数周 | 无痛范围内慢速、有控制的动作 | **爆发与大重量**。组织仍在改建，回满量易再伤 |
| **慢性期** | 更久 | 正常渐进 | 只靠“一直压炎症”掩盖问题——说明源头还在 |

**限制分两类，待遇不同**（`kind` 字段）：

- **长期**：结构性、无症状、永久（如一侧过头受限）。**只改动作选择**（按 rule 扫 impact／load／overhead），**不降高强度额度**——它不占恢复预算。
- **阶段性**：可逆、正在占恢复预算（伤后恢复期、急性症状）。除了扫动作，**周高强度课上限定为 3 次（平时 4 次）**；clear_when 满足（症状消退、推进后不适几小时内消退、24 小时无静息痛与疲劳加重）之前不加回 4。这条挂进强度账，与球、强泳、重下肢、质量跑同账。

未标注 `kind` 的按**阶段性**处理——不知道是否在占预算时，保守那一侧。

**解除条件（`clear_when`）怎么写**——写错比不写更危险：

- **不写「症状消失即可解除」「不疼了就行」**。这是用一句话把限制清掉，跟当初用一句话设限制是同一个毛病。
- 必须挂在**可观察的记录**上，三种写法任选，都要能被人按记录核：①按原剂量连续完成 N 次且次晨回基线；②某项功能测试达到具体数值；③影像确认愈合（骨的问题只此一条，见第三节）。
- 必须写明 **N 和基线是什么**：N 是次数还是周数、回基线指哪几项（晨痛／肿胀／跛行／动作散）、由谁记录。写「连续两周无晨痛」可以，写「感觉好了」不行。
- **解除只针对这一条，不连带其他条**：每条限制各自写、各自解。解除一条时要在复审记录里点名是哪一个 `region`／`rule`，其余条目维持原状。
- 解除由复评触发，不由日历触发：`until_week` 到期先进复评（`review`），**不自动解除**。

**分期按组织类型与次晨反应判断，不按固定日历。** 不同组织差得很远：肌肉以周计，肌腱以月计，骨以月计，且已声明该类损伤时须影像确认愈合才谈冲击。同一部位反复发作、或每次回到某个动作就复发，说明当前分期不合适——退回上一期重做，不要按日子硬往前推。（这是判断信号，不是「分期判断错了」的结论：先退回来观察，不退回来就看不到真假。）

## 四、七个动作族 × 三档限制

第一档是**能在全范围全负荷下做**，不用列。下表只写需要改的两档：

| 族 | 降级（还能练） | 暂缓（不练这个位） | 缺的能力 |
|---|---|---|---|
| **① 负重髋铰链** | 六角杠（中立握）或哑铃单腿硬拉；减重量、缩 ROM | 硬拉族暂停；髋伸改髋桥、单腿髋桥、瑞士球／滑板屈腿、北欧腿弯举 | 最大力量、后链负荷能力 |
| **② 膝主导** | 箱式蹲控深度、手扶支撑、缩 ROM；单腿优先 | 膝主导位暂停；保留等长（靠墙蹲、西班牙蹲）；下肢靠髋主导 | 膝主导最大力量与冲击耐受 |
| **③ 水平推** | 地板卧推（※包内补充）缩 ROM；哑铃换杠铃（轨迹更自由） | 闭链俯卧撑；仍不行则等长推 | 水平推的负重上限 |
| **④ 垂直推（过顶）** | 半程推举，只用可控范围，不加重量 | 垂直推暂缓；推的量全给水平推与斜推 | **过头稳定性**（补不回来） |
| **⑤ 垂直拉** | 弹力带辅助引体；缩 ROM 的下拉 | 垂直拉暂缓。**不拿水平拉顶替** | 整个垂直拉方向 |
| **⑥ 水平拉** | 反向划船、单臂支撑划船；改握法、减重量 | 水平拉暂缓；保留等长（悬垂静止） | 水平拉的负重上限 |
| **⑦ 冲击** | 低幅、软地面、缩距离；蹲跳改为快速蹲（不离地） | 有氧改泳、风阻单车、划船机、椭圆机；爆发改药球投掷（无腾空） | 落地与变向耐受 |

**⑦ 是唯一不能“少跑一点”的族**：冲击受限必须换无冲击有氧，否则有氧能力跟着一起丢。

## 五、单侧受限

- 健侧正常练，不因为患侧跟着降量。
- 患侧做可控范围或等长。
- **不为了对称把动作改成双侧**：双侧化会把健侧一起拖到患侧水平。
- 记差，但不追对称。

## 六、疼痛与负荷的判定：3/10

### 加量闸门（训练负荷的前置条件，不是医学许可）

**触发式，不靠登记**：出现任何部位的疼痛、晨起僵硬或次晨不适，本节立刻生效——不论有没有在本节登记过、也不论是不是训练引起的。即使使用者尚未登记限制或不认为属于损伤，已报告的相关症状仍触发此规则。

**适用范围**：本节只管**无确诊伤病、症状新发、且没有红旗**的情况。出现下列任一红旗，**直接去评估，不进闸门、不自行减量观察**：夜间静息痛、明显肿胀、麻木或无力、关节卡锁、外伤后不能负重。已经确诊的伤病按诊断方与治疗方的负荷意见走，本节只作辅助——**它是训练安排的前置条件，不是诊断，也不是治疗许可。**

**管哪些加量**：加重、加组、加距离、**加密组、压缩休息、增加频次**、进入下一阶段。凡是让同一剂量变得更重、更多、更密、更频繁的都算。10×50 配 45 秒休息没事，配 30 秒就出事——肩袖不会因为「划数没涨」就安全。

**三层：停／复核／加。各管一件事，没有一层能越权。**

- **停（当场执行，不等复核）**：本课疼痛 **>3/10**、动作当场变形，或出现红旗 → 当场停或退，本次不再推。
- **复核（只回答"这次要不要改"，不回答"能不能加"）**：本课 ≤3/10 且次晨回到基线 → 只表示**按原剂量练完、不用改**。它**不构成加量许可**。它也不是红线：训练后的迟发酸痛（课后 12–24 小时才出现、1–2 天消退）属正常反应，**不把「次晨有点酸」判成过量**。
- **过量（到这一步才谈减）**：推进后不适**几小时内就消退** → 按原剂量继续；**到 24 小时仍有疲劳加重、无力加重或痉挛** → 判为活动量推进过量，退一档。**静息痛不在这条里**：训练后 24 小时仍痛、或夜间静息痛，按上面适用范围的**红旗**直接去评估，不吃「退一档」这条——**红旗优先，两条不许挑宽松的用**。
- **「退一档」＝回到这次之前实际执行过、身体已经耐受过的那一组具体参数**（负重、组数、次数、距离、强度或休息之一），只退诱发变量。全文凡写「退一档」都指这一节。
  - **不用「上一档」这种相对说法**：课表里的休息是**预先写定的单值**、正常执行照表走，所以「上一档休息」多数时候并不存在。
  - **能退的前提是有已耐受的历史值**：用户说过练到第几组、哪一课有反应、之前用的是多少，才退得到那个值。
  - **没有历史值就不叫退档**：直接写新的参数和理由（改负重／组数／次数／距离／强度／休息，各是多少、为什么），不写「退一档」这三个字。
  - **休息只在两种情况下动**：①原先的休息本身被压缩过（45″ 压到 30″），退回压缩前那个值；②用户主动要求调整时重新指定休息并写明数值。正常执行不改预设休息。
  - **回程**：按退回来的那一组连续完成 2 次、次晨回基线，才加回**原剂量**；**不加回更大**。退过档直接跳回原量，等于把已经验证失败的剂量当成通过。
  - 回程的 2 次是**包内参数**，不是教材剂量。
- **加（回项目自身判据）**：RPE 是否达标、配速是否允许、阶段是否推进，**再加一条动作层面的拦截**——同一动作最近两次课**没有被症状拦过**。这一条是**被动拦截，不是要用户连续两次上报「无不适」**：没报问题就视为没被拦；报了就拦下、走退一档。项目标准不得单独放行：「划数没涨」不等于「无新症状」。
- **取消「自动恢复上一次没通过的加量」**：症状消了不等于那个量已经通过验证。从**当前已耐受的剂量**按项目递进规则重走，不跳回上次失败的那一档。

**这条的来源与适用范围要分开写**：`>3/10 停`、`≤3/10 只作复核`、`最近两次同动作没引出症状`、`取消自动恢复` 全部是**本包自定**，没有教材出处。`24 小时仍有静息痛／疲劳加重／无力／痉挛＝推进过量` 与 `迟发酸痛属正常反应` 出自 Kisner《Therapeutic Exercise》第 8 版 BOX 10.2，但**原文的适用人群是软组织损伤亚急性期**，用到无伤常规训练上属**本包外推**，不是原书对健康人训练的结论。

**闸门打开期间照常练，不是停练**，**先退诱发变量**。**密度只有一个判据：间歇与休息被压缩**（45 秒压到 30 秒、组间 90 秒压到 60 秒）。总量上涨（16×50→12×50 那是降总量）、频次增加（两跑改一跑那是降频次）、强度上升，各自是**另一个变量**，不能挂在"密度"名下——挂错了，砍的就不是诱发源。泳、跑的过用多由间歇被压诱发，深蹲硬拉多由强度诱发。**没有线索时才用默认顺序**：**①间歇 → ②总量 → ③频次 → ④强度**。这是默认值，不是通则。**技术段、纠正段、激活段默认保留**——受限关节当天能不能吃负荷，靠的正是它们；但**如果这些动作本身就是当日诱发源**（例如半跪踝松动、胸椎旋转当场引出症状），改该动作或降剂量，不是整段删掉，也不是硬留着。

**出口（止损，不是放行）**：连续两周都停或都退 → 停下来做一次真实评估，不继续原地等。没有这一步，闸门执行到第三周一定退化成「反正一直不加」。但**「自动恢复上次失败的那个增量」不算出口**——那不是出口，是把没验证过的量重新当成已验证过的。

### 当日上限

| 训练中疼痛 | 当次动作 |
|---|---|
| **0–3/10** | 可以继续本课既定剂量 |
| **>3/10** | 减重量、放慢速度，本次不推 |

（0 = 不痛，10 = 无法忍受。）

**这个数字只当当日上限，不当进阶许可。** 疼痛分数是当下的主观读数，反映不出组织耐受；拿它自动加量是最容易复发的做法。次晨反应有现成回填位（[输出规格](output-spec.md)的「当晚反应／次晨反应」），判定规则见上面三层的「复核」与「过量」，不用这张表反推。

### 重新加载的写法

- 极慢重复：**3–5 秒起、3–5 秒落**。
- 每周 **2 次不连续日**，3 组 10–15 次。
- 加重看上面两个条件，一次只动一个变量（先重量，再次数，不同时加）。
- 加到「只够做 5–6 次的重量」就停在这个档，不再追加重。

## 七、症状消失后的尾巴

症状没了不等于组织好了。肌腱与结缔组织的适应以**月**计，比疼痛消退慢得多；疼痛消失时组织仍在高周转。

所以：**症状消退后仍要维持针对性负荷训练一段时间**，不能直接回原计划。跳过这段尾巴是复发的主要来源。具体维持多久按次晨反应逐周判断，不预设固定周数。

## 八、重返不是“不疼了”

按**里程碑倒推**：从目标回归日往前排，每一步的准入是“能耐受当前这一步”，不是“已经不疼”。

以膝伤回球场为例（倒序）：

全场对抗 → 小场多人 → 少人战术 → 有轻度对抗的专项 → 无对抗专项 → 只做动作不判读 → 有球多向移动 → 无球多向移动

训练计划同理：要用回原主项位，先进它的降级版、能耐受、再加量，最后才回原重量与原组次。

一条底线：**在受伤、受损的系统上建表现是可能的，但不建议**——像在烂地基上盖房子。

## 九、红旗：退出训练流程，不是换动作

以下不属于“换个动作继续”，是停下并转专业：

| 系统 | 红旗 |
|---|---|
| 心血管／神经 | 运动前呼吸困难、心悸或心动过速、胸痛、头晕、头痛、感觉异常、麻木、视觉障碍、恶心呕吐 |
| 肌骨 | **肌无力**、小腿疼痛肿胀（排除深静脉血栓前） |

另外两条训练内红线：

- **影像未确认骨愈合 → 不做冲击与跑跳**。**触发范围：仅当使用者已声明存在骨折或骨应力损伤、或有医嘱限制跑跳时才成立；未声明就不适用——不向使用者索要影像，也不要求先做检查才给计划**。**触发后按部位、风险及已有专业要求执行，不一律设禁**：仅在适用指南或医嘱要求时，把影像愈合作为条件（骨应力损伤中影像愈合证据属高风险情况的复跑条件之一，不是所有情况的统一要求）；**医嘱明确禁止跑跳的一律不排**。包内不下临床结论，按适用指南与专业评估。**本节与各专项段都不写通用的降档数字**：跑量处理见 `run-programming.md` 五·六，腾空与主项处理见 `functional-session.md` 三（①支），泳侧下肢加载点见 `swim-programming.md` 末节。三处都只给触发式分支，具体动作与剂量按**部位、风险分级、已有专业要求**确定，不设百分比、不设备用组次。触发后这是硬门槛，不是“看感觉”，也不是“退一档就行”——**「退一档」的步长定义见第六节，它只处理剂量，不处理能不能做冲击这件事**。
- **冲击支路要分三类，别混成一条**：①影像未确认或医嘱禁止 → 本阶段不排落地冲击，换无腾空替代；②允许冲击但落地技能／基线不足 → 按探针剂量分级暴露，用低阶版；③当天肿痛跛 → **只取消当次**，阶段计划不动；但**后续受影响训练要按症状、已有专业要求和复评结果调整，不自动恢复原剂量**——「不砍阶段」不等于明天照原样上。出现红旗（肿胀明显、不能负重、夜间痛、单侧异常）时，走停止与进一步评估，不套这一支。把③写成①，等于用一次反应砍掉整个阶段；把红旗写成③，等于拿一张取消当次的单子掩盖该评估的问题。
- 关节交锁、打软腿、明显不稳、夜间痛或静息痛 → 停，转专业。

## 九·五、中间层：不算红旗，但别自己扛

红旗之下还有个中间层。**这一层最容易被跳过**：不构成红旗、又不怎么疼，于是直接按"减点量继续练"处理，练两周没好再减，循环到变成慢性。

**出现任一条，先去做一次评估，不要先改计划：**

| 判据 | 为什么不能自己调 |
|---|---|
| 同一部位疼 **2 周以上没改善**，或「停练就轻、一练就回」反复两轮 | 说明负荷与组织耐受不匹配，光减量找不到原因 |
| 每做到**某个固定动作或距离**就疼（如跑到 3 km、蹲到某个深度） | 按具体问题处理：查动作细节与负荷轨迹；反复出现且影响日常时建议评估（本包不做诊断）。换动作是临时回避，不是解决 |
| 已换过**两个动作族**仍然复发 | 问题不在动作选择上 |
| 疼痛开始影响**日常生活**（走路、上下楼、睡觉翻身） | 已经不是训练范畴 |
| 肿胀、关节卡顿、打软腿、明显不稳 | 需要查结构，不是调剂量 |
| 有明确外伤史（扭了一下、听到响声）后持续不适 | 排除结构性损伤前不排负荷 |

**去做什么**：运动医学科、康复科或物理治疗，做一次评估拿到明确结论——**是哪个结构、允许什么、禁止什么、多久复查**。带着这个结论回来，才进 `design_context.limitations`（`no_impact`／`no_load`／`no_overhead`），脚本会按它扫全计划。

**回排课的条件**：拿到明确限制或诊断；只有"多休息"这类含糊结论时，按最保守的一档处理（该部位 `no_load`＋`no_impact`），并写明复查时间。

**评估在前、排课在后**：跳过评估直接排课，等于拿计划当诊断用。

## 十、能力缺口怎么写进计划

- 写一行“**本阶段不发展：过头稳定性**”。
- 不静默换动作：换了动作名字就要跟着换，不能留着原名。
- 不因为一个模式受限贬掉整条线，能保的全保。

## 十一、禁则

- 不做诊断，不说“你这是 XX 综合征”。
- 不用阶段性限制去永久换动作族。
- 不把“垂直拉不可用”用水平拉顶替，只能暂缓。
- 不拿“不疼了”当重返标准。
- 不跳过症状消退后的针对性负荷期——长度按次晨反应逐周判断，不预设固定周数。
- 不在亚急性期做爆发与大重量（到没到慢性期看次晨反应与复发情况，不看过了几周）。
- 不为了对称把单侧受限改成双侧。
- 红旗症状不归训练计划处理。
